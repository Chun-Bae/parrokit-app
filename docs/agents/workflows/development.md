# Development Workflow

이 문서는 선택적인 참고 지침이다.

1. 관련 코드와 현재 변경 사항을 확인한다.
2. 사용자가 원하는 동작을 구현하는 데 필요한 범위를 수정한다.
3. 변경에 맞는 정적 분석, 빌드, 실행 또는 테스트로 확인한다.
4. 결과와 검증하지 못한 부분을 간결하게 알린다.

- 작은 UI 실험은 한 파일에서 시작할 수 있다.
- 상세 설계나 문서 작성, 레이어 분리, 테스트 추가를 모든 변경의 선행 조건으로 두지 않는다.
- 기존 기능과 데이터를 보존하고 무관한 리팩터링은 피한다.
- 커밋과 푸시는 사용자가 요청한 경우에만 진행한다.
