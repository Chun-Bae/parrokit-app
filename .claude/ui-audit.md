## 시뮬레이터 조작 메모

- **하단 탭바는 즉시 탭이 안 먹는다.** `duration: 0.15`를 주면 먹는다.
  BackdropFilter가 깔린 떠 있는 탭바라 합성 탭이 너무 짧으면 무시되는 것으로 보인다.
  실제 손가락 터치의 문제는 아닐 가능성이 크다. 앱 버그로 단정하지 말 것.
- 딥링크용 URL 스킴은 없다(OAuth 콜백만). 화면 이동은 탭으로만 가능하다.
- 화면 좌표 변환: 스크린샷 표시 좌표 × 0.4777 = device points

## 기록

### 2026-11-12 1단계

**다크 모드는 멀쩡하다.** 처음에 "다크로 안 바뀐다"고 본 것은 오진이었다.
앱 테마 설정이 `라이트`로 지정돼 있어서 iOS가 다크여도 라이트로 그린 것이다.
`시스템`으로 바꾸니 iOS 외형을 그대로 따른다. `ThemeMode` 배선
(`app.dart`, `theme_provider.dart`, `app_theme.dart`)에 문제 없음.

확인한 화면:

| 화면 | 모드 | 결과 |
|---|---|---|
| 홈 | 라이트 | 정상 |
| 커뮤니티 게시판 목록 | 라이트 | 정상 |
| 더보기 | 다크 | **정상** — 패롯/크래커 칩 배경이 다크 soft 색으로 제대로 나온다. 색 작업이 의도대로 동작 |
| 홈 설정 다이얼로그 | 라이트 | 정상 |

**말풍선 잘림은 오진이었다.** 다시 보니 스크롤 위치 때문이었고 말풍선 자체는
안전영역 안에 제대로 들어온다.
