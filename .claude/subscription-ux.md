# 구독·저장 UI/UX 설계 (2026-11-15)

`.claude/subscription-plan.md`의 요구사항을 화면으로 옮긴 것. 글귀는 여기 적은 것을 그대로 쓴다.
4차 원칙을 이어받는다: **버튼에는 이름을 붙이고, 위치가 아니라 상태로 말하고, 앱 말투('~어요')로 적는다.**

---

## 1. 저장 — "어디에 둘지"를 묻지 않는다

지금은 사용자가 저장 위치를 고른다. 앞으로는 **구독 여부가 정한다**. 화면은 위치 대신 상태를 말한다.

| 지금 | 앞으로 |
|---|---|
| 보관함 상단 저장 위치 탭 `기기 · 서버 · Google Drive` | **탭 없앰.** 클립은 한 목록에 모아 보여 준다 |
| 클립 줄의 칩 `기기` / `서버` / `Google Drive` | `이 기기에만` / `백업됨` 두 가지 |
| 옮기기 시트(기기·서버·Drive 중 고르기) | **없앰.** 구독자는 저장하면 서버로 간다 |
| 더보기 `저장 용량 · Google Drive` | `저장 용량` |
| 새 클립 저장 시 위치 고르기 | 묻지 않음 |

### 클립 줄의 상태 칩

- **백업됨** (구독자, 서버에 올라간 클립) — 회색 칩, 구름 아이콘
- **이 기기에만** (무료, 또는 아직 못 올린 클립) — 회색 칩, 휴대폰 아이콘
- **올리는 중** (업로드 중) — 진행 표시가 도는 칩
- **올리지 못함** (용량 초과·네트워크 실패) — 주의 색 칩. 누르면 까닭과 다시 시도

무료 사용자에게는 칩을 아예 안 보여 준다(전부 '이 기기에만'이라 정보가 없다).
대신 보관함 맨 위에 한 줄: **"이 기기에만 있어요. 폰을 바꾸면 사라져요."** + `백업 파일 만들기`

### 저장 용량 (더보기 > 저장 용량)

구독자:
```
저장 용량
[■■■■■□□□□□]  2.1GB / 5GB 사용
기기에 받아 둔 영상 71MB          [정리]
```
무료:
```
저장 용량
이 기기에만 저장돼요. 백업 파일을 만들어 두면 안전해요.
[백업 파일 만들기]
구독하면 서버에 자동으로 백업돼요.  [구독 보기]
```

## 2. Google Drive 걷어내기

사용자가 정했다: **Drive는 뺀다, 남은 데이터는 지워져도 된다, 옮겨 주는 흐름은 새로 만들지 않는다.**
다만 이미 Drive 클립이 있는 사람 화면이 조용히 깨지면 안 되므로 **안내 한 줄**은 둔다.
가져오기 버튼은 이미 있는 옮기기 기능(`moveClipToLocal`)을 부르는 것뿐, 새 흐름이 아니다.

보관함 맨 위(Drive 클립이 있을 때만):
```
Google Drive 저장은 이제 쓰지 않아요
가져오면 이 기기에서 계속 볼 수 있어요. 가져오면 Drive에 있던 파일은 지워져요.
[기기로 가져오기]
```

- 더보기의 `Google Drive 연동`·`연동 해제` 줄: 없앤다.
- 옮기기 시트의 `Google Drive` 선택지: 없앤다.
- `storageMode = 'gdrive'`인 클립을 눌렀을 때: 재생은 그대로 되고(받아 둔 파일이 있으면),
  없으면 **"Drive에 있던 영상이에요. 기기로 가져와 주세요."**
- 가져오기가 끝나면 토스트 **"기기로 가져왔어요."**

## 3. 구독 화면

### 3-1. 더보기 > 구독 줄

```
구독
무료                                  >      ← 구독 안 함
라이트 · 다음 결제일 12월 15일          >      ← 구독 중
```
무료일 때 부제: **"광고 없이, 매달 패롯을 받아요."**

### 3-2. 구독 고르기 화면 (새로 만듦)

RevenueCat Paywall 대신 **우리 화면**을 쓴다. 스토어 심사 요건(값·주기·자동 갱신·해지·약관·복원)을
우리 말투로 담아야 하고, 혜택이 패롯·용량·한도라서 설명이 필요하기 때문이다.

```
                구독

지금 무료예요
광고를 보고 패롯 3개를 받고 있어요.

┌─────────────────────────────┐
│ 라이트            월 ₩2,900  │
│ 광고 없이                    │
│ 매달 패롯 100개              │
│ 서버 백업 5GB                │
│ 뜻 채우기 하루 15번          │
│            [라이트 시작하기]  │
└─────────────────────────────┘
┌─────────────────────────────┐
│ 프로              월 ₩7,900  │
│ 라이트에 더해                │
│ 매달 패롯 400개              │
│ 서버 백업 30GB               │
│ 뜻 채우기 하루 60번          │
│            [프로 시작하기]    │
└─────────────────────────────┘

언제든 스토어에서 해지할 수 있어요. 해지하지 않으면 매달 자동으로 결제돼요.
받은 패롯은 그달 안에 써요. 남으면 다음 달로 넘어가지 않아요.

[이미 구독했다면 구매 복원]
[이용약관]  [개인정보 처리방침]
```

- 값은 **스토어가 주는 지역 가격**을 그대로 보여 준다(코드에 숫자를 박지 않는다).
- 스토어 상품을 못 불러오면: **"지금은 구독을 불러오지 못했어요. 잠시 뒤 다시 열어 주세요."**
  (버튼은 꺼 둔다. 베타처럼 상품이 아예 없을 때도 같은 화면.)

### 3-3. 구독 중 화면

```
라이트
다음 결제일 12월 15일

이번 달 패롯   ■■■■■■□□□□  62 / 100 남음
서버 백업      ■■□□□□□□□□  1.1GB / 5GB

[프로로 올리기]
[구독 관리]        ← 스토어 구독 화면으로
[구매 복원]
```

상태별 안내 한 줄:
- 결제 밀림(grace): **"결제가 밀렸어요. 스토어에서 결제 수단을 확인해 주세요."** (혜택은 유지)
- 해지 예약: **"12월 15일에 끝나요. 그때까지는 그대로 쓸 수 있어요."**
- 끝남: 더보기 줄이 `무료`로 돌아가고, 보관함 맨 위에 **"서버 백업이 끝났어요. 받아 둔 영상은 기기에 남아 있어요."**

### 3-4. 패롯이 모자랄 때

지금은 토스트 한 줄(`패롯이 부족합니다. (필요 5 / 보유 4)`)뿐이다. 시트로 바꾼다.

```
패롯이 모자라요
이번 작업에 5개가 필요한데 4개가 있어요.

[광고 보고 3개 받기]
[패롯 충전하기]
[구독 보기]        ← 무료일 때만
```

### 3-5. 서버 용량이 찼을 때

```
서버가 가득 찼어요
5GB를 다 썼어요. 안 보는 영상을 지우거나 프로로 올리면 더 담을 수 있어요.
[보관함 정리하기]  [프로로 올리기]
```

## 4. 말과 이름 규칙

| 쓰는 말 | 쓰지 않는 말 |
|---|---|
| 구독 | 멤버십, 프리미엄 플랜 |
| 라이트 / 프로 | Light / Pro, 베이직 |
| 매달 패롯 100개 | 월 100 코인, 100P |
| 서버 백업 | 클라우드 저장, 원격 저장소 |
| 이 기기에만 | 로컬, 디바이스 |
| 구독 관리 / 구매 복원 | 관리하기, 복원 |
| 해지 | 취소, 구독 취소 |

- 금액 뒤에 '/월' 대신 **'월 ₩2,900'**처럼 앞에 붙인다.
- 남은 패롯은 **'62 / 100 남음'** 꼴. 쓴 양이 아니라 남은 양을 적는다(문장 도우미 한도는 '오늘 1/3회 사용'이라 반대인데, 이쪽은 '남은 것'이 사용자 관심사다).

## 5. 화면별 체크리스트 (스토어 심사)

구독 고르기 화면 하나에 전부 있어야 한다.
- [ ] 티어 이름과 값(지역 가격), 결제 주기(월)
- [ ] 자동 갱신된다는 말과 해지 방법
- [ ] 구매 복원 버튼
- [ ] 이용약관·개인정보 처리방침 링크
- [ ] 받은 패롯의 유효 기간(그달 안)

## 6. 만드는 순서 (UI 기준)

1. **Drive 안내와 입구 제거** — 보관함 안내 줄, 저장 위치 탭·옮기기 시트·더보기 연동 줄 정리
2. **상태 칩** — `이 기기에만` / `백업됨` / `올리는 중` / `올리지 못함`
3. **구독 줄과 고르기 화면** — 스토어 상품이 없어도 열리고, 버튼만 꺼진 상태로 보이게
4. **구독 중 화면** — 가짜 티어(`PK_FAKE_TIER`)로 라이트·다크 확인
5. **패롯 부족 시트, 용량 초과 안내**

각 조각마다: 글귀를 한 파일에 모으고 → 위젯 테스트(글귀·상태별 보이기) → 시뮬레이터 라이트·다크 확인.
