# 구독 — 요구사항과 단계 (2026-11-15)

루프가 이 문서를 보고 일한다. 결정이 바뀌면 여기부터 고친다.

## 사용자가 정한 것

- **저장은 서버와 기기 둘뿐이다.** Google Drive는 뺀다.
- **Drive에 있던 내 클립은 지워져도 된다.** 다른 사용자도 쓰지 않는다고 본다.
  → 옮겨 주는 흐름을 따로 만들지 않는다. 연동 해제와 함께 정리한다.
- 구독을 **만드는 방향으로 진행한다**(계획만 세우는 단계는 끝).

## 아직 안 정한 것 (물어보지 말고 아래 기본값으로 가되, 피드백 오면 바꾼다)

| 것 | 기본값 |
|---|---|
| 티어 | 무료 · 라이트 · 프로 (셋) |
| 값 | 라이트 ₩2,900/월, 프로 ₩7,900/월 (화면에는 스토어 가격을 쓰고 숫자를 코드에 박지 않는다) |
| 매달 주는 패롯 | 라이트 100, 프로 400. **기간이 끝나면 사라지는 별도 잔액**(`subParrots`)으로 둔다 |
| 서버 저장 용량 | 무료 0, 라이트 5GB, 프로 30GB |
| 문장 도우미 하루 한도 | 무료 3, 라이트 15, 프로 60 |
| 광고 | 무료만 본다. `parrokit_ads_removed`를 이미 산 사람은 구독 없이도 광고 없음 |

## 단계

각 단계는 **그 단계만으로 analyze·test가 통과하고 앱이 돌아가야 한다.**
스토어 상품 등록과 함수·규칙 배포는 사용자 몫이라, 코드는 그것 없이도 동작해야 한다
(기본값은 '무료'로 떨어지고, 가짜 구독 상태로 화면을 확인할 수 있어야 한다).

### 1단계 — Google Drive 걷어내기
- 더보기의 Drive 연동 입구, 옮기기 시트의 'Google Drive' 선택지, 저장 위치 탭의 Drive를 없앤다.
- `disconnectGoogleDriveAfterLocalMove`는 남겨 두되 화면에서는 부르지 않는다.
  이미 Drive에 클립이 있는 사람에게는 보관함에 한 줄로 알린다:
  "Drive 저장은 더 쓰지 않아요. 기기로 가져오면 계속 볼 수 있어요." + 가져오기 버튼.
- `storageMode='gdrive'` 행을 만나도 앱이 깨지지 않아야 한다(읽기 호환 유지, 스키마 변경 금지).
- 다 지운 뒤 `google_drive_storage_service.dart`와 동기화 경로를 제거한다. 테스트도 함께 정리.
- **완료 기준**: Drive 없이 보관함·쇼츠·백업·저장 용량 화면이 모두 정상. analyze·test 통과.

### 2단계 — 티어를 서버가 정하게
- `users/{uid}.subscription = {tier, status, periodEnd, store, updatedAt}`.
- RevenueCat Webhook을 받는 함수 `onSubscriptionEvent`(갱신·만료·환불·유예 처리, 멱등).
- Firestore 규칙: `subscription`은 앱이 못 쓴다 → **배포 필요**에 명령 한 줄.
- 앱 `SubscriptionProvider`: 서버 값 우선, 없으면 RevenueCat `CustomerInfo`, 둘 다 없으면 무료.
  `IapProvider.isPremium`은 `tier != free`로 계산되게 덮는다.
- 개발 빌드에서 티어를 바꿔 보는 길(`--dart-define=PK_FAKE_TIER=pro`)을 둔다. 출시 빌드에는 안 들어간다.
- **완료 기준**: 티어 계산·webhook 단위 테스트. 화면 변화는 없다.

### 3단계 — 혜택 연결
- 광고: `AdProvider.premium = tier != free`.
- 매달 패롯: 함수가 기간마다 `applyLedger` 키 `sub_grant_{uid}_{tier}_{periodStart}`로 `subParrots` 지급.
  쓸 때 `subParrots` → `parrots` 순으로 깎는다. 기간이 끝나면 남은 `subParrots`는 0으로.
- 문장 도우미 한도: `config/subscription`의 티어별 값을 본다.
- 서버 저장 용량: Storage 트리거로 `users/{uid}.storage.usedBytes`를 서버가 집계하고,
  올리기 전에 함수가 남은 용량을 승인한다(앱 숫자를 믿지 않는다).
- **완료 기준**: 티어별 한도·지급·소진 테스트. 가짜 티어로 화면 확인.

### 4단계 — 사는 길과 관리 화면
- 더보기 '결제' 섹션을 다시 켠다: 지금 티어, 다음 결제일, 이번 달 남은 패롯, 구독 관리, 구매 복원.
- 패롯이 모자랄 때 뜨는 안내에서 구독 화면으로 갈 수 있게.
- 베타 안내('결제 기능이 빠져 있어요')를 그때 함께 고친다.
- **완료 기준**: 라이트·다크 확인. 결제 버튼은 누르지 않는다(스토어 상품이 없으면 눌러도 실패해야 정상).

### 5단계 — 저장 단일화 마무리
- 사용자에게 '저장 위치 고르기'를 묻지 않는다. 구독자는 서버, 무료는 기기.
- 화면 말은 위치가 아니라 상태로: '백업됨' / '이 기기에만 있어요'.
- 기기 파일은 재생 캐시로 남긴다(전송 비용 때문에 반드시 유지).
- 무료 사용자에게는 백업 파일 내보내기를 안전망으로 안내한다.

## 지켜야 할 것

- 스토어 상품·entitlement 등록, 함수·규칙 배포는 **사용자가 한다**. 코드는 그것 없이도 돌아간다.
- 돈·잔액은 서버만 바꾼다. 장부 키는 멱등.
- 가격 숫자를 앱에 박지 않는다. 스토어가 주는 값을 쓴다.
- 스토어 심사: 구독 화면에 값·주기·자동 갱신·해지 방법·약관 링크·복원 버튼.
- 영상 만들기는 모델 종료로 꺼져 있다. 프로 혜택에 넣지 않는다.
