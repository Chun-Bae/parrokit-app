# 기능 안건

3차 작업 중 화면과 코드를 보며 떠오른 것. **하나도 구현하지 않았다.** 고를 것만 고르면 된다.

크기: 작음(반나절 안), 중간(하루~이틀), 큼(며칠 이상, 설계 필요).
우선순위: 1(먼저) ~ 3(나중).

## 2. 새 기능

### 2-0. 홈 '지금 뜨는 문장'을 실제 데이터에 연결 — 우선 1, 작음~중간
- **문제:** 지금 이 섹션은 `trending_sentences_preview.dart`에 **코드로 박힌 예시 문장**이다.
  사용자 이름(dailybird, Mina, Joon…), 좋아요 수(284, 193…), "방금·3분 전"이 모두 가짜인데
  "LIVE" 배지와 "사람들이 지금 저장하고 있는 표현이에요"라는 문구가 붙어 있다. 하트·저장을
  눌러도 화면 안에서만 바뀌고 어디에도 남지 않는다. 같은 시점에 보관함 "공유된 문장"은
  실제로 0개다. 출시하면 사용자를 속이는 화면이 된다
- **자리:** 같은 자리. 보관함 "공유된 문장"이 이미 읽는 `shared_sentence_repository`에서
  좋아요 순 상위 몇 개를 가져온다. 공유 문장이 없으면 섹션을 숨기거나 "첫 공유 문장을
  올려 보세요"로 바꾼다
- **서버·DB:** 좋아요 순 정렬용 색인 정도
- **급하면:** 연결 전까지 "LIVE"와 "사람들이 지금 저장하고 있는" 문구, 가짜 사용자 이름과
  숫자만 빼고 "추천 표현"으로 두는 방법도 있다. 기능을 바꾸는 판단이라 이번에 하지 않았다

### 2-1. 연속 학습일(스트릭)과 하루 목표 알림 — 우선 1, 중간
- **문제:** 홈에 학습 캘린더와 하루 목표가 있지만, 앱을 안 열면 아무것도 상기시키지 않는다
- **자리:** 캘린더 카드 제목 옆 "🔥 3일 연속", 더보기 > 알림 설정에 "하루 목표 알림 시각"
- **구현:** 연속일은 이미 있는 날짜별 연습 수로 계산(로컬). 알림은 `flutter_local_notifications`로 로컬 예약이면 서버가 필요 없다
- **서버·DB:** 없음

### 2-2. 복습 큐(간격 반복) — 우선 1, 중간
- **문제:** 친밀도(새 문장/익히는 중/익숙함)는 있는데 "오늘 무엇을 다시 볼지"를 정해 주지 않는다. 지금 계정에도 익히는 중 7, 익숙함 0이다
- **자리:** 학습 허브 "학습 방법" 아래 "오늘 복습할 문장 n개" 카드, 홈 "학습하러 가기" 아래 한 줄
- **구현:** 문장 활동 기록(`sentence_activity_store`)에 마지막 연습일·성공 여부가 있으니, 단계별 간격(1·3·7·14일)으로 오늘 대상만 고른다
- **서버·DB:** 없음(로컬 필드 하나 추가 가능성)

### 2-3. 탭바를 다시 누르면 그 탭의 첫 화면으로 — 우선 1, 작음
- **문제:** 하위 화면에 들어간 채로 같은 탭을 누르면 아무 일도 없다(1차 UI 점검 `ui-decisions.md` "기능이라 안 건드린 것"에 기록)
- **자리:** `AppShell` 탭 선택 처리. 이미 선택된 탭이면 그 탭 스택을 루트로 돌리고, 루트면 맨 위로 스크롤
- **서버·DB:** 없음. 내비게이션 동작이 바뀌므로 이번 루프에서는 손대지 않았다

### 2-4. 질문 목록에 "전체" 필터 — 우선 2, 작음
- **문제:** 질문 탭 필터가 채택 완료/답변 대기중/화제/오래된 넷이고 기본이 "답변 대기중"이라 모든 질문을 한 번에 볼 방법이 없다(1차 기록)
- **자리:** `CommunityFilters.question` 맨 앞에 "전체"
- **서버·DB:** 없음

### 2-5. 패롯·크래커 사용 내역 — 우선 2, 중간
- **문제:** 잔액만 보이고 어디서 얼마가 들어오고 나갔는지 볼 수 없다. 결제·광고 보상 문의가 오면 확인할 방법도 없다
- **자리:** 더보기 > 계정 카드의 패롯·크래커 배지를 누르면 내역 화면
- **구현:** `review-findings.md`의 서버 이전 설계에 있는 `wallet_ledger`를 그대로 읽는다. 서버 이전과 함께 하는 게 맞다
- **서버·DB:** 서버 이전에 포함

### 2-6. 계정 연결(구글·네이버·카카오) — 우선 2, 중간
- **문제:** 같은 이메일로 다른 방법 로그인 시 네이버는 막히고, 막히지 않는 쪽은 계정이 둘로 갈라진다(A7)
- **자리:** 더보기 > 계정 > "로그인 방법 연결"
- **서버·DB:** 네이버·카카오는 커스텀 토큰이라 매핑 컬렉션과 함수 수정 필요

### 2-7. 따라 말하기 발음 점수 — 우선 3, 큼
- **문제:** 학습 허브가 "음성 인식과 자동 경험치 지급은 준비 중"이라고 스스로 말한다. 핵심 학습 동작인데 결과가 없다
- **구현:** 기기 음성 인식(`speech_to_text`가 이미 의존성에 있다)으로 문자열 유사도 점수부터. 홈 무대에는 이미 비슷한 점수 표시가 있다(`speechPassScore`)
- **서버·DB:** 없음(기기 인식). 정밀 채점은 서버 모델이 필요해 큼

### 2-8. 홈 화면 위젯 "오늘의 문장" — 우선 3, 중간
- **문제:** 앱을 열지 않아도 문장 하나를 보게 하면 하루 목표 달성이 쉬워진다
- **구현:** iOS WidgetKit·Android AppWidget + `home_widget` 패키지. 네이티브 코드 필요
- **서버·DB:** 없음

### 2-9. 쇼츠에 Google Drive 클립도 — 우선 2, 중간
- **문제:** 쇼츠는 `ownerScope`가 device·app_account인 클립만 고른다. Drive(cloud_account) 클립만
  있는 사용자는 쇼츠가 늘 비어 있다. 그런데 같은 파일 아래쪽에는 Drive 캐시 경로를 찾는 분기가
  있다(`8b3a1683`). 조회 조건 때문에 그 분기에는 한 번도 들어가지 않는다
- **구현:** 조회 조건에 `cloud_account & ownerKey == googleDriveStorageService.currentAccountKey()`를
  더한다. 캐시가 없는 Drive 클립은 재생 파일이 없으니, 캐시가 있는 것만 고르거나 넘길 때
  내려받기를 시작해야 한다
- **서버·DB:** 없음
